# 초성게임 (멀티모드 + 싱글모드)

## User-visible outcomes

지인들이 URL 공유만으로 방에 모여 멀티모드로 초성게임 10라운드를 겨루고 순위를 확인할 수 있다. 혼자서도 싱글모드로 제한시간 내 타임어택 기록에 도전할 수 있다.

## Approved scope

- 멀티모드: 방 생성/참여(URL + 닉네임), 대기실 채팅, 방장의 카테고리·난이도 설정, 라운드 진행(초성 제시 → 아이템 사용 → 정답 판정), 라운드 중 별도의 아이템 획득용 미니 문제, 실시간 순위 사이드바, 10라운드 진행 후 순위 발표
- 싱글모드: 여러 초성 문제가 위에서 아래로 순차적으로 떨어지는 화면에서 제한시간 내 최대한 많이 클리어하는 모드. 카테고리를 모두 클리어하면 클리어 시간을, 못 채우면 클리어 개수를 기준으로 하는 전체 랭킹(TOP 10)에 이름이 오른다.
- 아이템 시스템: 라운드 승자 또는 아이템 미니 문제를 푼 참가자에게 랜덤 아이템 1개 지급. 공격형(3초 지연시키기, 초성 하나 가리기, 글자를 거꾸로 입력해야 인식되게 하기, 아이템 훔치기, 입력 지우기)과 방어형(공격 무효화)
- 난이도별 초성 마스킹 정도 조절(하/중/상)
- 사자성어·속담·동물·음식·도시·수도·과일·색깔·직업·스포츠 10개 카테고리

## Observable acceptance criteria

- 방장이 방을 만들면 공유 가능한 URL이 생성되고, 다른 사용자가 그 URL로 접속해 닉네임을 입력하면 대기실에 합류한다.
- 방장이 카테고리와 난이도를 선택하고 시작하면, 참가자 전원에게 동일한 초성 문제가 동시에 표시된다.
- 난이도에 따라 노출되는 초성 글자 수가 다르게 표시된다(예: "유구무언" 기준 하="유구ㅁ언", 중="유ㄱ무ㅇ", 상은 한 음절만 힌트로 남기고 나머지를 초성으로 가린다).
- 제한시간 내에 정답을 처음 제출한 참가자가 해당 라운드의 승자로 표시되고, 랜덤 아이템 하나가 지급된다.
- 참가자가 보유한 공격형 아이템을 특정 상대에게 사용하면, 대상에게 해당 방해 효과(지연/가림/역순 입력)가 적용된다.
- 방어형 아이템을 사용한 참가자는 공격형 아이템의 효과를 받지 않는다.
- 제한시간이 끝날 때까지 아무도 정답을 맞히지 못하면 승자 없이 다음 라운드로 넘어간다.
- 라운드 진행 중에는 화면 오른쪽에 참가자 이름과 현재 라운드 승수를 기준으로 한 순위가 실시간으로 갱신되어 표시된다.
- 10라운드가 모두 끝나면 라운드 승리 횟수를 기준으로 순위표가 표시되고, 동률인 참가자는 평균 정답 소요시간이 빠른 순으로 정렬된다.
- 싱글모드에서는 초성 문제가 무작위 속도로 위에서 아래로 떨어지며 계속 나타나고, 시간 안에 풀지 못해도 사라지지 않고 화면에 남아 기다린다.
- 싱글모드에서 선택한 카테고리의 문제를 모두 클리어하면, 제한시간이 남아 있어도 즉시 결과 화면으로 종료된다.
- 정답을 잘못 제출하면 오답임을 알 수 있게 표시하고 입력창을 비운다.
- 방 참여와 싱글모드 진입 모두 회원가입 절차 없이 가능하다. 닉네임 입력 시 랜덤 생성 버튼을 제공한다.
- 싱글모드 화면 오른쪽에는 전체 랭킹 TOP 10이 표시된다. 카테고리를 모두 클리어한 기록은 클리어 시간이 빠른 순으로, 그 아래로 다 채우지 못한 기록은 클리어한 개수가 많은 순으로 정렬된다.
- 멀티모드 대기실에는 참가자·설정과 별도로 채팅 영역이 있어 참가자끼리 실시간으로 메시지를 주고받을 수 있다. 방 공유 URL은 기본적으로 접혀 있고, 클릭하면 펼쳐진다.
- 라운드가 진행되는 동안 메인 문제 아래에 참가자별로 별도의 아이템 획득용 문제가 계속 제공된다. 이를 맞히면 즉시 랜덤 아이템을 얻고 새 문제로 바뀐다.
- 아이템 위에 마우스를 올리면 말풍선 형태로 설명이 표시된다.

## Settled constraints and rationale

- 멀티모드는 2인 이상 4인 이하로 진행한다. (PRODUCT.md에서 확정)
- 참여는 URL과 닉네임만으로 가능하며 회원가입은 없다. 캐주얼한 사용성을 지키기 위함이다. (PRODUCT.md에서 확정)
- 순위는 라운드 승리 횟수를 기준으로 매기고, 동률이면 평균 정답 소요시간이 빠른 쪽을 우선한다. 기존 라운드 승부 규칙("1명이 맞히면 라운드 종료")과 자연스럽게 이어지고 구현·표시가 단순하기 때문이다. (이번 세션에서 확정)
- 문제·카테고리 데이터는 사전 제작된 DB를 기반으로 지속 업데이트한다. (PRODUCT.md에서 확정)
- 라운드 제한시간은 문제당 15초다. (이번 세션에서 확정)
- 상 난이도는 모든 음절을 가리지 않고 한 음절을 항상 힌트로 남긴다. 전부 가리면 난이도가 지나치게 가혹하기 때문이다. (사용자가 확정)
- 싱글모드는 선택한 카테고리의 문제를 모두 맞히면 제한시간과 무관하게 즉시 종료한다. (사용자가 확정)
- 싱글모드에서 떨어지는 문제는 시간 안에 못 풀어도 사라지지 않고 화면에 남아 기다린다. 너무 빨리 사라지면 안 된다는 사용자 피드백에 따른 것이다. (사용자가 확정)
- 싱글모드 랭킹은 카테고리·난이도를 구분하지 않는 전체 랭킹 하나로 운영한다. "전체 랭킹"을 요청한 사용자 의도를 그대로 반영했다. (사용자가 확정)
- 카테고리는 사자성어·속담·동물·음식·도시·수도·과일·색깔·직업·스포츠 10개로 운영한다. (사용자가 확정)

## Assumptions

- 아이템은 라운드 진행 중(제한시간 카운트다운이 도는 동안) 아무 시점에나 사용할 수 있다고 가정한다. 상대를 방해하는 목적상 자연스러운 사용 방식이며, 되돌리기 쉬운 결정이다.
- 방어형 아이템은 보유만으로 자동 발동되지 않고, 참가자가 능동적으로 사용해야 효과가 적용된다고 가정한다. 다른 아이템과 조작 방식을 통일해 UI를 단순하게 유지하기 위함이다.
- 정답 판정은 공백을 제거한 완전 일치 방식으로 하고, 오탈자는 허용하지 않는다고 가정한다. 구현이 단순하고 초성게임 특성상 정확한 단어를 맞히는 것이 핵심이기 때문이다.
- 아이템은 획득 시 1개씩 누적되고 사용하면 소모되며, 보유 개수에 별도 제한은 두지 않는다고 가정한다. 최대 10라운드 안에서 자연스럽게 상한이 생긴다.
- 같은 종류의 아이템을 여러 개 보유하면 UI에는 하나로 묶여 개수(×N)로 표시하고, 사용하면 그중 하나가 소모되어 사라진다고 가정한다. (사용자가 확정)
- 아이템 획득용 미니 문제는 참가자마다 따로 주어지며(같은 문제를 여러 명이 다투지 않음), 라운드 승패나 순위에는 영향을 주지 않는 부가 보상으로 가정한다.
- "아이템 훔치기"·"입력 지우기"는 공격형 아이템으로 분류해 방어막으로 막을 수 있다고 가정한다. 기존 방해 아이템과의 일관성을 위해서다.

## Off-limits areas and why

- 계정/로그인 시스템: PRODUCT.md에서 회원가입 없이 캐주얼하게 참여하는 것으로 이미 확정했으므로 다루지 않는다.
- 지인이 아닌 상대와의 랜덤 매칭: 지인 기반 URL 공유 방식으로 확정했으므로 범위 밖이다.

## Deferred points

- 방장이 게임 중간에 나가는 경우의 처리 방식
- 참가자가 라운드 중간에 나가거나 재접속하는 경우의 처리 방식
- 구체적인 카테고리 목록(예: 사자성어, 속담 등)과 실제 문제 데이터
- 방장이 라운드 제한시간(15초)을 직접 조정할 수 있게 할지 여부

## Remaining risks

- 아이템 사용 타이밍에 대한 가정이 실제 기대와 다르면 라운드 진행 UI를 다시 설계해야 할 수 있다.
- 방어형 아이템의 발동 방식(능동 사용 vs 자동 발동)에 대한 가정이 틀리면 아이템 UI·로직을 재작업해야 할 수 있다.
- 방장 이탈, 참가자 이탈·재접속 처리가 정의되지 않아 멀티모드 진행 중 안정성에 영향을 줄 수 있다.
- 싱글모드 전체 랭킹이 카테고리를 구분하지 않아, 단어 수가 적은 카테고리(예: 속담 6개)가 많은 카테고리(예: 사자성어 10개)보다 클리어 시간이 유리해 랭킹 공정성이 떨어질 수 있다.
- 대기실 채팅과 방 상태 조회가 같은 폴링 주기(0.7초)를 공유해 채팅이 즉시성이 낮게 느껴질 수 있다.
